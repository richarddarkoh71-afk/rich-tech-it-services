# Rich Tech IT Services

A simple, modern business website for an IT services company.

## Project structure
- index.html
- styles.css
- script.js
- assets/

## How to run
Open index.html directly in a browser, or serve the folder with a local web server.

Example:
```bash
python -m http.server 8000
```

Then open:
```text
http://localhost:8000
```

## Features
- Responsive homepage layout
- Services section (6 services)
- About section with company values
- Case study/project showcase
- Pricing plans
- Client reviews
- Contact form
- Mobile-friendly design

## Customization
Edit the following to add your business details:
- index.html: Add your phone, email, address, hours
- styles.css: Change colors, fonts, spacing
- script.js: Add form submission backend
- assets/: Replace with your actual business images/logos
